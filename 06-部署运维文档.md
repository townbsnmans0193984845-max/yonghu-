```

        │  Port: 3000   │  │  Port: 3001 │  │  Port: 3002 │
```

### 服务器配置要求

**最小配置**（测试环境）:
- CPU: 2核
- 内存: 4GB
- 硬盘: 40GB SSD
- 带宽: 5Mbps

**推荐配置**（生产环境）:
- CPU: 4核+
- 内存: 8GB+
- 硬盘: 100GB SSD
- 带宽: 10Mbps+

**操作系统**:
- Ubuntu 20.04+ / CentOS 8+
- Docker 20.10+
- Docker Compose 2.0+

## 环境准备

### 1. 安装Docker

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动Docker
sudo systemctl start docker
sudo systemctl enable docker

# 验证安装
docker --version
```

### 2. 安装Docker Compose

```bash
# 下载最新版本
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# 添加执行权限
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker-compose --version
```

### 3. 配置防火墙

```bash
# 开放必要端口
sudo ufw allow 22    # SSH
sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS

# 启用防火墙
sudo ufw enable
```

### 4. 安装Nginx（宿主机）

```bash
sudo apt update
sudo apt install nginx -y

# 启动Nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 2. 环境变量配置

```bash
# /opt/timecoin-job/.env

# 应用配置

# Redis配置

# JWT配置
```

### 3. Docker Compose配置

```yaml
# /opt/timecoin-job/docker-compose.yml
version: '3.8'

services:
  # PostgreSQL数据库
  postgres:
    image: postgres:14-alpine
    container_name: timecoin-postgres
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: ${DATABASE_PASSWORD}
      POSTGRES_DB: timecoin_job
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./backend/prisma/init.sql:/docker-entrypoint-initdb.d/init.sql
    ports:
      - "5432:5432"
    restart: always
    networks:
      - timecoin-network
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Redis缓存
  redis:
    image: redis:7-alpine
    container_name: timecoin-redis
    command: redis-server --requirepass ${REDIS_PASSWORD}
    volumes:
      - redis_data:/data
    ports:
      - "6379:6379"
    restart: always
    networks:
      - timecoin-network
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  # 后端API服务
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: timecoin-backend
    environment:
      - NODE_ENV=production
      - DATABASE_URL=${DATABASE_URL}
      - REDIS_URL=redis://:${REDIS_PASSWORD}@redis:6379
      - JWT_SECRET=${JWT_SECRET}
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    ports:
      - "3001:3001"
    volumes:
      - ./backend/logs:/app/logs
    restart: always
    networks:
      - timecoin-network

  # 前端H5应用
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
      args:
        - VITE_API_BASE_URL=https://api.timecoin-job.com
    container_name: timecoin-frontend
    ports:
      - "3000:80"
    restart: always
    networks:
      - timecoin-network

  # 管理后台
  admin:
    build:
      context: ./admin
      dockerfile: Dockerfile
      args:
        - VITE_API_BASE_URL=https://api.timecoin-job.com
    container_name: timecoin-admin
    ports:
      - "3002:80"
    restart: always
    networks:
      - timecoin-network

volumes:
  postgres_data:
  redis_data:

networks:
  timecoin-network:
    driver: bridge
```

### 4. 前端Dockerfile

```dockerfile
# /opt/timecoin-job/frontend/Dockerfile
```

## 数据库部署

### 1. 初始化数据库

```bash
# 进入后端容器
docker-compose exec backend sh

# 执行数据库迁移
npx prisma migrate deploy

# 或手动执行SQL
psql $DATABASE_URL < prisma/init.sql
```

### 2. 数据库备份

```bash
# 创建备份脚本
cat > /opt/backup.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/opt/backups"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/timecoin_job_$DATE.sql"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
docker-compose exec -T postgres pg_dump -U postgres timecoin_job > $BACKUP_FILE

# 压缩备份
gzip $BACKUP_FILE

# 删除7天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete

echo "Backup completed: $BACKUP_FILE.gz"
EOF

# 添加执行权限
chmod +x /opt/backup.sh

# 设置定时任务（每天凌晨2点）
crontab -e
# 添加: 0 2 * * * /opt/backup.sh >> /var/log/backup.log 2>&1
```

### 3. 数据库恢复

```bash
# 解压备份
gunzip /opt/backups/timecoin_job_20260205_020000.sql.gz

# 恢复数据库
docker-compose exec -T postgres psql -U postgres timecoin_job < /opt/backups/timecoin_job_20260205_020000.sql
```

## Nginx配置

### 1. 前端Nginx配置

```nginx
# /opt/timecoin-job/frontend/.nginx.conf
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    # SPA路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # API代理
    location /api {
        proxy_pass http://backend:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 2. 宿主机Nginx配置（反向代理+SSL）

```nginx
# /etc/nginx/sites-available/timecoin-job

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name timecoin-job.com www.timecoin-job.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS配置
server {
    listen 443 ssl http2;
    server_name timecoin-job.com www.timecoin-job.com;

    # SSL证书配置
    ssl_certificate /etc/letsencrypt/live/timecoin-job.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/timecoin-job.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # 前端H5
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# 管理后台
server {
    listen 443 ssl http2;
    server_name admin.timecoin-job.com;

    # SSL证书配置
    ssl_certificate /etc/letsencrypt/live/admin.timecoin-job.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/admin.timecoin-job.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    location / {
        proxy_pass http://localhost:3002;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 3. 告警配置

```yaml
# prometheus/alerts.yml
groups:
  - name: alert_rules
    interval: 30s
    rules:
      # 服务下线告警
      - alert: ServiceDown
        expr: up == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "服务 {{ $labels.instance }} 下线"

      # CPU使用率过高
      - alert: HighCPUUsage
        expr: 100 - (avg by(instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "实例 {{ $labels.instance }} CPU使用率过高"

      # 内存使用率过高
      - alert: HighMemoryUsage
        expr: (1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100 > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "实例 {{ $labels.instance }} 内存使用率过高"

      # 磁盘空间不足
      - alert: DiskSpaceLow
        expr: (node_filesystem_avail_bytes{mountpoint="/"} / node_filesystem_size_bytes{mountpoint="/"}) * 100 < 20
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "实例 {{ $labels.instance }} 磁盘空间不足"
```

## 应急预案

### 1. 服务宕机

**现象**: 网站无法访问

**排查步骤**:
1. 检查服务器状态: `ping timecoin-job.com`
2. 检查Docker服务: `docker-compose ps`
3. 检查Nginx服务: `sudo systemctl status nginx`
4. 查看错误日志: `docker-compose logs`

**解决方案**:
```bash
# 重启所有服务
docker-compose restart

# 如果Docker异常，重启Docker
sudo systemctl restart docker

# 如果Nginx异常，重启Nginx
sudo systemctl restart nginx
```

### 2. 数据库连接失败

**现象**: API返回数据库错误

**排查步骤**:
1. 检查PostgreSQL容器状态: `docker-compose ps postgres`
2. 检查数据库日志: `docker-compose logs postgres`
3. 测试数据库连接: `docker-compose exec postgres pg_isready`

**解决方案**:
```bash
# 重启数据库
docker-compose restart postgres

# 如果数据损坏，从备份恢复
# 见"数据库恢复"章节
```

### 3. 磁盘空间不足

**现象**: 服务无法写入日志或数据

**排查步骤**:
1. 检查磁盘使用: `df -h`
2. 查找大文件: `du -sh /var/lib/docker/*`

**解决方案**:
```bash
# 清理Docker日志
docker system prune -a

# 清理应用日志
rm -rf /opt/timecoin-job/backend/logs/*.log

# 清理旧的数据库备份
find /opt/backups -name "*.sql.gz" -mtime +30 -delete
```

### 4. 内存不足

**现象**: 服务响应缓慢或OOM

**排查步骤**:
1. 查看内存使用: `free -h`
2. 查看进程内存: `docker stats`

**解决方案**:
```bash
# 重启服务释放内存
docker-compose restart

# 调整Docker内存限制（在docker-compose.yml中）
services:
  backend:
    mem_limit: 512m
    memswap_limit: 1g
```

## 性能优化

### 1. 数据库优化

```sql
-- 创建索引
CREATE INDEX CONCURRENTLY idx_jobs_status_created ON jobs(status, created_at DESC);
CREATE INDEX CONCURRENTLY idx_applications_status_date ON applications(status, applied_date DESC);

-- 查看慢查询
SELECT query, mean_exec_time, calls
FROM pg_stat_statements
ORDER BY mean_exec_time DESC
LIMIT 10;
```

### 2. Redis缓存优化

```bash
# 设置最大内存限制
# 在redis配置中添加
maxmemory 256mb
maxmemory-policy allkeys-lru
```

### 3. Nginx优化

```nginx
# 启用缓存
proxy_cache_path /var/cache/nginx levels=1:2 keys_zone=api_cache:10m max_size=100m inactive=60m;

location /api/jobs {
    proxy_cache api_cache;
    proxy_cache_valid 200 5m;
    proxy_pass http://localhost:3001;
}
```
