## 🎯 项目概述

### 产品定位

**职兼兼职兼平台**是一个即时结算、强约束履约的兼职招聘平台，解决传统兼职市场的痛点：
- ❌ 薪资拖欠
- ❌ 鸽子率高（放鸽子）
- ❌ 纠纷难处理

### MVP核心功能

#### ✅ v1.0包含
- 手机号注册登录（验证码）
- 双身份体系（兼职者/招聘方）
- 岗位发布与浏览
- 报名与审核流程
- 打卡功能（上岗/下岗）
- 简化结算（不涉及真实支付）
- 基础管理后台

#### ❌ v2.0预留
- 真实支付集成（支付宝/微信）
- 钱包系统（充值/提现）
- 实时聊天（WebSocket IM）
- 争议仲裁系统
- 信用分算法
- 地图推荐

## 🚀 快速开始

### 1. 环境准备

```bash
# 克隆项目(假设使用Git)
git clone https://github.com/your-org/timecoin-job.git
cd timecoin-job

# 安装依赖
pnpm install
```

### 2. 数据库初始化

```bash
# 执行数据库迁移
cd apps/api
npx prisma migrate dev --name init

# 或手动执行SQL脚本
psql -U postgres -d timecoin_job -f 附录/数据库表结构SQL.md
```

### 3. 启动开发服务器

```bash
# 启动后端
cd apps/api
pnpm dev

# 启动前端
cd apps/mobile
pnpm dev
```

         └────────────┬────────────┘
                      │
    ┌─────────────────┼─────────────────┐
    │                 │                 │
┌───▼───┐      ┌──────▼──────┐   ┌─────▼─────┐

└───┬───┘      └──────┬──────┘   └─────┬─────┘

         └─────────────────────────┘

### 数据流

```
用户请求 → API Gateway → 鉴权验证 → 业务逻辑 → 数据库

                                 返回响应
```

## 🔌 API总览

### 认证模块
- `POST /auth/send-code` - 发送验证码
- `POST /auth/login` - 登录
- `POST /auth/register` - 注册
- `GET /auth/me` - 获取当前用户

### 岗位模块
- `GET /jobs` - 获取岗位列表
- `GET /jobs/:id` - 获取岗位详情
- `POST /jobs` - 创建岗位
- `PUT /jobs/:id` - 更新岗位
- `DELETE /jobs/:id` - 删除岗位

### 报名模块
- `POST /jobs/:jobId/apply` - 报名
- `GET /applications/me` - 获取我的报名
- `POST /applications/:id/accept` - 录用
- `POST /applications/:id/reject` - 拒绝
- `POST /applications/:id/check-in` - 上岗打卡
- `POST /applications/:id/check-out` - 下岗打卡
- `POST /applications/:id/complete` - 确认完工

**详细API文档**: 见 `附录/API接口字典.md`
